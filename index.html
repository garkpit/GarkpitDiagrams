GarkpitDiagrams

Excalidraw diagrams from a small TypeScript DSL. Describe nodes and edges; the library lays them out, measures every label in the real Excalifont, fit-checks the result and writes editable .excalidraw files, SVG, PNG previews and A4 PDFs.

Real font metrics. Labels are measured with Excalifont's glyph advances (fontkit), so shapes grow to fit their text instead of guessing a character width.

A fit check on every render. Text inside its shape, arrows routed round nodes, nothing overlapping or straddling a lane, file integrity, legibility once printed.

Editable output. Every drawing is a valid Excalidraw v2 file that opens and edits in excalidraw.com; SVGs carry the font, so they look the same everywhere.

diagrams render scenes.ts --out images      # .excalidraw + .svg, fit-checked
diagrams preview scenes.ts --out previews   # PNG previews to look at
diagrams check drawing.excalidraw           # fit-check any file, drawn by anything
diagrams pdf doc.md                         # Markdown with diagrams to an A4 PDF
